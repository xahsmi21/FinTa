# FinTa – المحاكي المالي الذكي
منصة تعليمية تفاعلية موجهة لطلاب المالية والمحاسبة، تعتمد على الذكاء الاصطناعي لتقديم مهام تطبيقية تساعد المستخدم على التدرب عمليًا على إعداد القوائم المالية وتحليلها داخل شيت تفاعلي. يقوم النظام بتقييم الحلول والتحقق من فهم الطالب، بينما يقدّم الذكاء الاصطناعي تصحيحًا فوريًا وشرحًا مبسطًا للأخطاء والملاحظات بهدف تحسين الأداء وتعزيز الفهم العملي.

---

## عن المشروع

تم تطوير **FinTa** ضمن **هاكاثون أمد**، بالتعاون مع **أكاديمية طويق** و **بنك الإنماء**. يهدف المشروع إلى سد الفجوة بين المعرفة النظرية والتطبيق العملي في مجال المحاسبة المالية، عبر توفير بيئة محاكاة تفاعلية مدعومة بالذكاء الاصطناعي.

### المشكلة التي يحلها المشروع:
- يعاني طلاب المحاسبة من صعوبة في تطبيق المفاهيم النظرية على أرض الواقع.
- الافتقار إلى أدوات تدريبية تفاعلية توفر تغذية راجعة فورية.
- صعوبة تتبع التقدم الفردي في المهارات المالية.


### الحل المقدم:
- منصة ويب تتيح للطلاب حل حالات دراسية مالية في بيئة محاكاة.
- نظام تقييم فوري بالذكاء الاصطناعي يقدم ملاحظات مخصصة.
- مسار تعلم متدرج يناسب مستوى كل طالب.
- لوحة تحكم شاملة لتتبع التقدم والإنجازات.
  
##التحديثات المستقبيلة:
- تحليل الاسهم واتخاذ القرار الناتج عن التحليل.
  
## المشكلة التي يحلها التحديث:
- اتخاذ قرار مالي لتعزيز ثقتهم باتخاذ القرار بناء على تحليلهم
- مجتمع قادر على اتخاذ القرار السليم في اختيار السهم

## الميزات الرئيسية

### للمستخدم 
- **محاكاة تفاعلية للقوائم المالية** – بيئة عمل تشبه جداول البيانات (Spreadsheet) لحل الحالات.
- **تقييم فوري بالذكاء الاصطناعي** – تحليل الإجابات، حساب النتيجة، وشرح الأخطاء.
- **مسار تعلم مخصص** – اختيار مستوى الصعوبة (مبتدئ / متوسط) مع فتح الحالات تدريجياً.
- **لوحة تحكم متكاملة** – عرض التقدم، الحالات المكتملة، والنتائج السابقة.
- **مصادقة آمنة** – تسجيل الدخول وحماية البيانات.

### للمنظمين 
- **منصة جاهزة للعرض** – يمكن تشغيلها محلياً دون الحاجة لخوادم خارجية.
- **سهولة التثبيت والتشغيل** – خطوات واضحة لتشغيل المشروع.

## التقنيات المستخدمة

### الواجهة الخلفية (Backend)
| التقنية | الاستخدام |
| :--- | :--- |
| **Python** | لغة البرمجة الأساسية |
| **FastAPI** | إطار العمل لبناء واجهات برمجة التطبيقات (API) |
| **SQLite & SQLAlchemy** | قاعدة البيانات و ORM |
| **Google Gemini API** | توليد التغذية الراجعة الذكية |
| **JWT & bcrypt** | المصادقة الآمنة وتشفير كلمات المرور |

### الواجهة الأمامية (Frontend)
| التقنية | الاستخدام |
| :--- | :--- |
| **HTML5, CSS, JavaScript** | بناء واجهة مستخدم تفاعلية |


### الأدوات والتكامل
| الأداة | الاستخدام |
| :--- | :--- |
| **Uvicorn** | تشغيل خادم FastAPI |
| **python-dotenv** | إدارة المتغيرات البيئية |
| **Alembic** | إدارة هيكل قاعدة البيانات |
| **HTTP.server** | تشغيل الواجهة الأمامية محلياً |

# تعليمات التشغيل
1- افتح الطرفية(cmd.exe)
```console
git clone https://github.com/xahsmi21/FinTa.git
cd path/to/FinTa
```

2- اكتب هذا الأمر:
```backend\venv\Scripts\activate.bat  ```

ثم اكتب لتنزيل المكتبات المستخدم للمشروع:
``` pip install -r backend\requirements.txt ```

3- الآن لتشغيل backend اكتب هذا الأمر:
```
cd backend\
python.exe main.py
```
اضغط Ctrl-C بشكل متكرر، لتوقف عمل backend.
ثم اكتب هذا الأمر:
``` python.exe -m app.seed```
ثم مرة اخرى شغل backend:
``` python.exe main.py ```

4- قم بفتح طرفية ثانية (cmd.exe) واذهب الى مجلد ```FinTa```
اكتب هذه الأوامر:
```backend\venv\Scripts\activate.bat  ```

بنفس الطرفية الثانية، اذهب لمجلد ```FinTa\frontend```
اكتب هذه الأمر:
``` python -m http.server 3000 ```

5- فتح المتصفح(web browser)، واكتب:
localhost:3000
